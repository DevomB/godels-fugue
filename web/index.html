Gödel's Fugue

Composes canons as a constraint problem and shows why every note is there. Pick a starting point, shape it, give each voice its player, listen, and save it. This is the C program compiled to WebAssembly, running in your browser.

Source Config keys Design notes

How does it work?
  1. A canon is one melody played against delayed copies of itself, so every note is heard again in the other voices.
  2. The melody has a form: a subject stated first, its opening bar brought back as a sequence, a contrasting climax, and a return before the cadence. Each phrase breathes at its end.
  3. Rules (stay in the key and in each instrument's range, consonant strong beats, no parallel fifths, a cadence) remove the pitches that cannot work; preferences rank what is left, and the solver collapses the piece note by note.
  4. Every removal is logged with the rule behind it, so any note can answer why is this here?, and you can try another value and hear the piece compose itself around it.
